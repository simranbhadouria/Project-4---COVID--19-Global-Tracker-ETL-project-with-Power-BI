# Project-4---COVID--19-Global-Tracker-ETL-project-with-Power-BI

Objective:

The COVID-19 Global Tracker aims to monitor and visualize the worldwide progression of the COVID-19 pandemic using reliable open-source data from Kaggle.
The project provides data-driven insights into how the virus spread globally, helping understand infection trends, recovery rates, and mortality patterns through interactive dashboards in Power BI.
Data Source:

Kaggle Datasets:

Novel Coronavirus 2019 Dataset (Johns Hopkins University)
COVID-19 World Vaccination Progress
Data Type: Time-series data (Date, Country, Confirmed, Deaths, Recovered, Vaccinations)
Time Period: Daily data for each country

Conclusion:

The COVID-19 Global Tracker successfully demonstrates how real-world health data can be transformed into actionable insights using data visualization tools.
By integrating data from Kaggle and processing it through Power BI
We built a centralized fact-based monitoring system for global pandemic progression.
The dashboard provides clear, interactive, and comparative analytics between regions and over time.
This project highlights the importance of data accuracy, consistency, and visualization in global health reporting.
